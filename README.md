# Task Tracker

Личный список задач со сроками и приоритетами.

## Автор
Воскобойник Людмила, 24ПИ2

## Сценарий
Пользователь добавляет задачу, указывает срок и приоритет, меняет статус
и находит просроченные записи.

## Стек
React, TypeScript, Vite

## Версия Node
24.21.0 (см. файл .node-version)

## Запуск
Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки
Остановите dev через Ctrl+C. Выполните в frontend:

```bash
npm run build
npm run preview
```

## Что работает сейчас
Регистрация и вход по email и паролю (Supabase Auth), выход. Личные страницы
доступны только после входа. Задачи хранятся в Supabase: создание, просмотр,
редактирование и удаление сохраняются после перезагрузки. Каждый пользователь
видит только свои задачи. Справочник тегов загружается из Supabase, есть
фильтр по статусу.

## Маршруты
- /auth - вход и регистрация
- /tasks - список
- /tasks/new - создание
- /tasks/:id - карточка
- /tasks/:id/edit - редактирование

## Модель доступа
- tags: читают все
- tasks: читает и изменяет только владелец (owner_id = auth.uid())

## Настройка Supabase
1. Создайте проект и включите вход по email.
2. В Authentication → URL Configuration укажите Site URL и Redirect URL
   (http://localhost:5173).
3. В SQL Editor выполните по порядку: миграцию 202611020001_initial_schema.sql,
   seed.sql, затем 202611070001_tasks_owner_policies.sql.
4. В frontend создайте .env.local по образцу .env.example.


Секретные ключи и пароль базы в репозиторий не добавляются.

## Текущие ограничения
Данные пока не сохраняются, форм добавления задач нет. Они появятся
в следующих лабораторных.
