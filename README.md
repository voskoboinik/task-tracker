# Task Tracker

Личный список задач со сроками и приоритетами.

## Автор
Воскобойник Людмила, 24ПИ2

## Сценарий
Пользователь добавляет задачу, указывает срок и приоритет, меняет статус
и находит просроченные записи.

## Стек
React, TypeScript, Vite

## Версия Node
24.21.0 (см. файл .node-version)

## Запуск
Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки
Остановите dev через Ctrl+C. Выполните в frontend:

```bash
npm run build
npm run preview
```

## Что работает сейчас
Список задач (/tasks), страница подробностей по id (/tasks/:id),
заглушка создания (/tasks/new), страница неизвестного адреса и
страница отсутствующей записи. Данные демонстрационные, хранятся
в коде (frontend/src/data/tasks.ts), не сохраняются между запусками.

## Текущие ограничения
Данные пока не сохраняются, форм добавления задач нет. Они появятся
в следующих лабораторных.
