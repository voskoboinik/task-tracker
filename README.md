# Task Tracker

Личный список задач со сроками и приоритетами.

## Автор
Воскобойник Людмила, 24ПИ2

## Сценарий
Пользователь добавляет задачу, указывает срок и приоритет, меняет статус
и находит просроченные записи.

## Стек
React, TypeScript, Vite

## Версия Node
24.21.0 (см. файл .node-version)

## Запуск
Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки
Остановите dev через Ctrl+C. Выполните в frontend:

```bash
npm run build
npm run preview
```

## Что работает сейчас
Начальный экран приложения: название, описание и раздел "Мои задачи"
с заглушкой списка.

## Текущие ограничения
Данные пока не сохраняются, форм добавления задач нет. Они появятся
в следующих лабораторных.

## Использование ИИ
ИИ помог разобраться со структурой проекта.
Результат я проверила сама: запуском в браузере и командой npm run build.
