# Task Tracker

Личный список задач со сроками и приоритетами.

## Автор
Воскобойник Людмила, 24ПИ2

## Сценарий
Пользователь добавляет задачу, указывает срок и приоритет, меняет статус
и находит просроченные записи.

## Стек
React, TypeScript, Vite

## Версия Node
24.21.0 (см. файл .node-version)

## Запуск
Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки
Остановите dev через Ctrl+C. Выполните в frontend:

```bash
npm run build
npm run preview
```

## Что работает сейчас
Список задач с фильтром по статусу (/tasks), подробности (/tasks/:id),
создание (/tasks/new) и редактирование (/tasks/:id/edit) через общую форму,
удаление с подтверждением. Справочник тегов загружается из Supabase
(таблица tags) с состояниями загрузки, ошибки, пустого результата,
повторной попыткой и кнопкой «Обновить справочник». Основные задачи
хранятся только в памяти вкладки: после обновления страницы
возвращаются демонстрационные записи.

## Настройка Supabase
1. Создайте проект в Supabase.
2. В SQL Editor выполните supabase/migrations/202611020001_initial_schema.sql,
   затем supabase/seed.sql.
3. В frontend создайте файл .env.local по образцу .env.example.

Переменные окружения:
- VITE_SUPABASE_URL
- VITE_SUPABASE_PUBLISHABLE_KEY

Секретные ключи и пароль базы в репозиторий не добавляются.

## Текущие ограничения
Данные пока не сохраняются, форм добавления задач нет. Они появятся
в следующих лабораторных.
