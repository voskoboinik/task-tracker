# Прогресс

## Лабораторная 1
- Создан проект React + TypeScript + Vite (frontend)
- Заменён стартовый экран на собственный (Task Tracker)
- Проверка типов и сборка проходят успешно
- Репозиторий опубликован на GitHub

## Шаги проверки
1. cd frontend, затем npm ci
2. npm run dev, открыть http://localhost:5173
3. Увидеть заголовок Task Tracker и раздел "Мои задачи"
4. npm run build, сборка проходит без ошибок
5. npm run preview, открыть адрес и проверить экран

Коммит: см. git log -1 --oneline

## Лабораторная 2
- Добавлены типы Task и 5 демонстрационных записей
- Создан компонент TaskCard, страницы TasksPage, TaskDetailsPage,
  NewTaskPage, NotFoundPage
- Подключён react-router: BrowserRouter, Routes, Outlet, useParams
- Общий layout AppLayout с навигацией
- Проверены переходы, прямое открытие карточки, пустой список,
  неизвестный путь и отсутствующая запись

Шаги проверки:
1. npm run dev, открыть /, /tasks, /tasks/t1 и /tasks/t2
2. Прямое открытие /tasks/t3 в новой вкладке и обновление страницы
3. Переход на /tasks/new, видна заглушка
4. Открыть /unknown и /tasks/missing — разные сообщения
5. npm run build, npm run preview — проверить сборку

Коммит: см. git log -1 --oneline

## Лабораторная 3
- Общий список задач поднят в App (useState), создание/изменение/удаление
  через функции createTask, updateTask, deleteTask
- Добавлен тип TaskDraft и переиспользуемая форма TaskForm
- Созданы NewTaskPage и EditTaskPage на основе общей формы
- TasksPage и TaskDetailsPage получают tasks через props, прямой импорт
  данных убран
- Добавлен локальный фильтр по статусу со сбросом
- Добавлено удаление с подтверждением (window.confirm)
- В layout добавлено пояснение о временном хранении данных

Шаги проверки:
1. npm run dev, создать новую задачу, проверить карточку и список
2. Отредактировать задачу, проверить изменения; проверить отмену без сохранения
3. Проверить ошибки валидации (пустое название, без срока, без описания для "Готово")
4. Переключить и сбросить фильтр по статусу
5. Удалить задачу с подтверждением, проверить /tasks/missing
6. Обновить страницу и убедиться, что вернулись демонстрационные данные
7. npm run build, npm run preview — повторить проверку в собранной версии

Коммит: см. git log -1 --oneline
